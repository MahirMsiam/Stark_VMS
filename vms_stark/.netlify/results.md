New projects on this team start out **private**. A private project can only be opened by people signed in to Netlify with access to it. Making it public is a dashboard setting, so no code changes are needed.

To make the site public:

1. Open Manage and search for 'visibility'.
2. Under **Project visibility**, choose **Edit visibility**. If a team default is applied, choose **Customize** first.
3. Select **Public**.
4. Click **Save**.

After you save, anyone can open https://stark-vms-lpco.netlify.app without signing in.

Notes:

- A project needs at least one successful production deploy before it can be made public. This project already has one, so the option should be available.
- You need to be the Team Owner, or a Developer with access to this project, to change the setting.
- To make all future projects public by default, open your team menu and change the default project visibility to **Public for new projects**.
